# Домашнее задание №1
## Реализация иммутабельного класса с изменяемым полем

### Описание
Реализован иммутабельный класс `ImmutableClass`, который содержит поле с изменяемым классом `MutableClass`.

### Принципы иммутабельности
1. **Класс объявлен как `final`** - предотвращает наследование
2. **Все поля объявлены как `final`** - гарантирует, что ссылки не изменятся
3. **Глубокая копия в конструкторе** - создается копия изменяемого объекта
4. **Защита геттеров** - возвращается копия изменяемого объекта
5. **Неизменяемые коллекции** - списки возвращаются через `Collections.unmodifiableList()`
6. **Методы для создания новых объектов** - `with...()` вместо сеттеров
