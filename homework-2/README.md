# Student & Book JSON Processor

Проект на Java, демонстрирующий работу с объектно-ориентированным программированием, сериализацией/десериализацией данных в формат JSON (с помощью библиотеки Jackson) и продвинутое использование Java Stream API.

## Цель проекта
Реализация консольного приложения, которое:
1. Создает иерархию классов `Student` и `Book`.
2. Генерирует текстовый файл в формате JSON с данными о студентах и их книгах (минимум 5 книг на студента).
3. Считывает данные из файла и обрабатывает их с помощью **единого конвейера Stream API** без использования каких-либо промежуточных переменных.
