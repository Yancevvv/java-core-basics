# Многопоточность в Java

Данный проект содержит реализации классических проблем многопоточности: **Deadlock** (взаимная блокировка), **Livelock** (живая блокировка), а также пример корректной синхронизации потоков для **последовательного вывода** данных.

## Структура проекта

- `Main.java` — главное меню для выбора и запуска нужного примера из консоли.
- `DeadlockExample.java` — демонстрация взаимной блокировки (Deadlock).
- `LivelockExample.java` — демонстрация живой блокировки (Livelock) с использованием `ReentrantLock.tryLock()`.
- `SequentialPrinting.java` — демонстрация поочередного вывода "1" и "2" двумя потоками с использованием `wait()` / `notifyAll()`.
